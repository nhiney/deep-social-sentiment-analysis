Chi tiết kiến trúc

Text

XLM-RoBERTa-base · Teencode normalization trước · [CLS] pooling → 768d

Tabular

FT-Transformer · 10 numerical + 4 categorical · Embedding → Transformer block → 192d

Fusion

Concat 768+192 = 960d · Linear(960→256) → ReLU → Dropout → Linear(256→7) → Softmax

XAI

LIME: tô màu token đóng góp · SHAP: feature importance tabular branch

💡 Teencode normalization đóng góp +3.1 F1-Macro so với raw text
